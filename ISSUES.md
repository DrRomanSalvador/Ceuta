# CeutIA — Confirmed Issues Register

This file tracks confirmed technical, architectural, operational, or documentation problems that require persistence beyond a single task.

## Issue Status

Use only:

- `OPEN`
- `IN_PROGRESS`
- `BLOCKED`
- `RESOLVED`
- `WONT_FIX`

## Issue Format

```text
## ISSUE-XXXX — Short title

- Status: OPEN
- Severity: CRITICAL | HIGH | MEDIUM | LOW
- Discovered: YYYY-MM-DD
- Reporter: <agent>
- Component: <component or file>

### Evidence
<observable evidence>

### Impact
<actual or demonstrated impact>

### Suspected cause
<cause, clearly marked as hypothesis if not proven>

### Resolution
<resolution when known>

### Verification
<verification performed>
```

## Rules

1. Record evidence, not speculation.
2. Do not create duplicate issues for the same confirmed problem.
3. Link related tasks or decisions when useful.
4. Do not mark an issue resolved without verification.
5. Preserve resolved issues for historical traceability.
