# CeutIA + SERPIENTE — Persistent Mission

This repository contains the persistent identity of the single continuous scientific-engineering mission shared by CeutIA and SERPIENTE.

A new agent instance must not start a new project or treat “Maximum Knowledge-to-Capability” as a separate phase.

Bootstrap:

1. Read `mission/CEUTIA_SERPIENTE_MISSION_STATE.json`.
2. Follow `mission/MISSION_BOOTSTRAP.md`.
3. Run the dependency-free validator in `mission/bootstrap.py`.
4. Reconcile the persisted state against current Git, code, tests, CI and authoritative scientific documents before continuing.

The repository is the continuity mechanism. Conversation context is not required for mission identity.
