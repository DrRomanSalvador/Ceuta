# ROMÁN — Collaboration Graph Amendment

ROMÁN is a peer mission. These edges extend the common collaboration graph without changing existing mission ownership.

| From | To | Purpose | Artifact |
|---|---|---|---|
| BIBLIOTECARIO | ROMAN | authorial source discovery/provenance | Authorial Evidence Packet |
| ESPÍA | ROMAN | scientific/methodological structures relevant to intellectual architecture | Scientific-to-Authorial Packet |
| ROMAN | ESPÍA | how scientific ideas are integrated/evolved in the authorial model | Authorial Scientific Interpretation |
| ROMAN | FORJA | claims requiring mathematical/statistical verification | Formal Verification Request |
| ROMAN | GROK | interpretations requiring falsification | Authorial Adversarial Request |
| ROMAN | INGENIERO | infrastructure/contract requirements | Mission Engineering Handoff |
| ROMAN | NOTARIO | evidence/provenance classification | Authorial Evidence Ledger Packet |

Every handoff retains source mission, target mission, timestamp, proposition, evidence level, source references, assumptions, validation status, uncertainty, conflict status and next action.

ROMÁN does not gain authority over recipient missions through these edges, and recipient missions do not gain authority to redefine ROMÁN's authorial model without evidence.
