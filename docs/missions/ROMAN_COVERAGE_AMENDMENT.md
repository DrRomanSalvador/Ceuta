# ROMÁN — Coverage Matrix Amendment

ROMÁN adds a distinct authorial/intellectual domain to the multi-mission system.

| Capability | ROMAN role |
|---|---|
| Authorial forensics | D/A/V/P within authorial evidence boundary |
| Intellectual architecture | D/A/V/P |
| Scientific reasoning as authored | A; handoff to ESPÍA/FORJA for domain validation |
| Systems thinking as authored | A; handoff to ESPÍA/NEXO as required |
| Style / rhetoric / narrative / metaphor | A/V within source corpus |
| Longitudinal evolution | A/V with temporal provenance |
| Contradiction analysis | A/P; unresolved conflicts remain explicit |
| Authenticity analysis | A/V; cannot establish identity from inference alone |
| Anti-style analysis | A/V; detects mismatch without treating generation as source evidence |
| Generation support | Partial; downstream application only, never evidence generation |

Mission ownership means who investigates the authorial/intellectual question, not that the capability is empirically solved. Source corpus completeness and external validation remain explicit dependencies.
