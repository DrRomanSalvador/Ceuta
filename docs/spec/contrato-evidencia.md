# Contrato de Evidencia — CeutIA

**Document class:** Normative contract
**Authority:** Binding on all evidence handling paths.

---

## Requisitos mínimos de toda evidencia

1. **Procedencia** — fuente, timestamp de captura, método de captura.
2. **Independencia** — declaración explícita de si es primaria o derivativa.
3. **Estado epistemológico** — una etiqueta del conjunto cerrado definido en `estados-epistemologicos.md`.
4. **Límites de uso** — PUBLIC o OWNER.
5. **Cadena de custodia** — trazabilidad desde la observación original.

---

## Prohibiciones absolutas

- Una fuente derivativa nunca cuenta como evidencia independiente.
- La confianza de evidencia nunca se convierte automáticamente en probabilidad del evento.
- No se permite promediar silenciosamente fuentes dependientes o contradictorias.
- No se permite omitir el estado epistemológico.
